# MathJam
------ 
## What is the MathJam?
This is a tutorial project to create your first multi-page website
The project's theme was to develop a platform for selling online mathematics courses for schoolchildren and students
It used HTML, CSS, and JS files
Partial russian language support is available

## How to use?
* download project as a .zip file
* Extract files from the archive
* open index.html with Visual Studio or another software development environment
* open index.html with Live server
* If you don't have LIve Server, install it with [the link](https://github.com/ritwickdey/vscode-live-server/tree/2669d78c8ff22e4d5b3f664523c3400c5893ec6f "Live server")
